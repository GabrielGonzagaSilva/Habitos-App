# Hábitos +

Um aplicativo para iOS, desenvolvido em Swift e SwiftUI, focado em ajudar você a registrar e alcançar suas metas diárias, transformando-as em hábitos.

## Funcionalidades:
- Registro de metas diárias.
- Interface amigável.
- Monitoramento do progresso.

## Tecnologias Utilizadas:
- Swift
- SwiftUI

## Objetivo:
Desenvolvido com a finalidade de aprimorar minhas habilidades na linguagem Swift e no uso do SwiftUI.
